LEARNHUB - ONLINE LEARNING PLATFORM ADMIN DASHBOARD

1. Install XAMPP or Laragon.
2. Copy the online_learning_dashboard folder into:
   XAMPP: C:\xampp\htdocs\
   Laragon: C:\laragon\www\
3. Start Apache. Start MySQL only when you need database features.
4. Open this address in your browser:
   http://localhost/online_learning_dashboard/

CURRENT FEATURES
- Responsive admin dashboard
- Sidebar navigation
- Summary cards for students, courses, instructors and revenue
- Recent courses table
- Recent activity panel
- PHP arrays and foreach loops

DATABASE CONNECTION
- The optional connection file is config/db.php.
- Database name is set to online_learning.
- Default XAMPP MySQL username is root and password is blank.
- Do not include config/db.php in index.php until you are ready to load real database records.
